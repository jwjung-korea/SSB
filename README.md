# SSB

Solid-state battery modeling workspace.

## Contents

- `simulations/elastic_plastic_coldspot/`: Abaqus lithium/LLZO elastic-plastic coldspot model, source UMAT, input files, scripts, compact logs, and presentation-ready post-processing results.

Large Abaqus result databases such as `.odb`, `.sim`, `.res`, `.prt`, `.mdl`, `.ipm`, and `.msg` are intentionally excluded from Git because they are generated artifacts and can exceed GitHub file limits.
