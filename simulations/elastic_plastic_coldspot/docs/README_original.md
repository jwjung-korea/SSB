# UMAT 리튬 전착 시뮬레이션 — Elastic-Plastic Coldspot 모델

## 개요

이 폴더는 **고체 전해질(LLZO) 위에 리튬이 전기화학적으로 증착(Plating)될 때 발생하는 기계적 변형**을 시뮬레이션합니다.

- **원본 코드:** Sooraj Narayan & Lallit Anand (2019), 점소성(Viscoplastic) UMAT
- **수정 코드:** 탄성-소성(Elastic-Plastic) + Voce 연화 + Coldspot 차등 성장 모델
- **UMAT 파일:** `umat_EP_coldspot.for`
- **해석 소프트웨어:** Abaqus/Standard 3DEXPERIENCE R2017x

## 1. 물성치 (Material Properties)

### 1.1 LLZO (Li₇La₃Zr₂O₁₂, 고체 전해질)

LLZO는 세라믹 계열의 고체 전해질로, 리튬 금속(E ≈ 7.2 GPa)보다 **약 20배 단단**합니다.
소성 변형이나 성장은 일어나지 않고 **순수 선형 탄성**으로만 거동합니다.

| 물성 | 값 | 단위 | 비고 |
|---|---|---|---|
| Young's modulus (E) | 150,000 | MPa | 리튬의 약 20배 |
| Poisson's ratio (ν) | 0.25 | - | |
| Shear modulus (G) | 60,000 | MPa | = E / 2(1+ν) |
| Bulk modulus (K) | 100,000 | MPa | = E / 3(1-2ν) |

> **역할:** LLZO는 리튬이 증착되는 "바닥판" 역할을 합니다.
> 리튬보다 훨씬 단단하기 때문에 거의 변형되지 않으며,
> 증착된 리튬이 팽창할 때 이를 억제하는 **구속 조건(Constraint)**으로 작용합니다.
> 이 구속 때문에 Seed 층 내부에 응력이 집중되고, 소성 변형이 유발됩니다.

### 1.2 LITHIUM_IP / LITHIUM_SUB (UMAT 재료)
`.inp` 파일의 `*User material, Constants=11`로 전달됩니다.

| # | 변수명 | LITHIUM_IP | LITHIUM_SUB | 의미 |
|:---:|---|:---:|:---:|---|
| 1 | `Eyoung` | 7200 | 7200 | 영률 (MPa) |
| 2 | `poisson` | 0.38 | 0.38 | 포아송 비 |
| 3 | `Y0` | 3.1 | 3.1 | 초기 항복 응력 (MPa) |
| 4 | `H0` | 5.7 | 5.7 | 경화(연화) 계수 (MPa) |
| 5 | `Ysat` | 2.0 | 2.0 | 포화 항복 응력 (MPa) |
| 6 | `ahard` | 2.0 | 2.0 | 경화 지수 |
| 7 | `Omega` | 1.3e-05 | 1.3e-05 | 부분 몰 부피 |
| 8 | `alpha1` | 0.0 | 0.0 | (미사용) |
| 9 | `alpha2` | 1.0 | 1.0 | (미사용) |
| 10 | `alpha3` | 0.0 | 0.0 | (미사용) |
| **11** | **`cdot`** | **103.643** | **0.0** | **농도 변화율 (1/s)** |

> **LITHIUM_IP vs LITHIUM_SUB의 유일한 차이는 `props(11) = cdot`입니다.**
> - LITHIUM_IP: cdot = 103.643 → Seed 층에서 리튬 증착/탈리 활성화
> - LITHIUM_SUB: cdot = 0.0 → 성장 없이 순수 탄소성 거동만

### 1.3 내부 파생 물성치

| 변수 | 수식 | 값 | 의미 |
|---|---|---|---|
| `Gshear` | E / 2(1+ν) | ≈ 2608.7 MPa | 전단 탄성 계수 |
| `Kbulk` | E / 3(1-2ν) | ≈ 10000 MPa | 체적 탄성 계수 |
| `S` (초기) | Y0 / √3 | ≈ 1.79 MPa | 초기 전단 저항 |
| `S̃` (포화) | Ysat / √3 | ≈ 1.155 MPa | 포화 전단 저항 |

## 2. 변형 분해 (Kinematics)

전체 변형 구배 F를 세 부분으로 곱분해합니다:

```
F = Fe · Fp · Fg

Fe: 탄성 변형 (응력 발생의 원인)
Fp: 소성 변형 (영구 변형, 항복 후 발생)
Fg: 성장 변형 (리튬 증착에 의한 부피 팽창)
```

### 성장 변형 (Fg)

리튬 증착 시 y-방향으로만 팽창합니다:

```
         ┌ 1    0    0 ┐
Fg  =    │ 0   λg₂   0 │      λg₂ = 1 + Ω · c(t)
         └ 0    0    1 ┘

Ω = 1.3e-05 (부분 몰 부피)
c(t) = 리튬 농도 (시간에 따라 변화)
```

## 3. 계산 흐름 (Computational Flow)

아래 순서대로 매 시간 스텝(Increment)마다 반복됩니다.

### Step 1: 성장 변형 Fg 계산
```
cdot 결정:
  ├─ LITHIUM_SUB → cdot = 0 (성장 없음)
  └─ LITHIUM_IP  → cdot = 103.643
       ├─ 매 2160초마다 부호 반전 (충전 ↔ 방전)
       └─ x = 9~11 영역 → cdot를 1/10로 감소 (Coldspot)

c_new = c_old + Δt · cdot        ← 농도 갱신
Fg(2,2) = 1 + Ω · c_new          ← y-방향 팽창량
```

### Step 2: 시행 탄성 상태 (Trial Elastic State)
```
Fi_tr = Fp_old · Fg_new           ← 비탄성 변형
Fe_tr = F · Fi_tr⁻¹              ← 시행 탄성 변형
    ↓
Ee_tr = ln(Ue_tr)                 ← 탄성 로그 변형률
    ↓
Me_tr = 2G·Ee0_tr + K·tr(Ee)·I   ← 시행 Mandel 응력
    ↓
τ̄_tr = √(½ · Me0:Me0)            ← 등가 전단 응력 ("지금 재료가 받는 힘")
```

### Step 3: 항복 판정
```
τ̄_tr  vs  S_old  비교

┌─ τ̄ ≤ S → 탄성! νP = 0, Fp 변화 없음
│
└─ τ̄ > S → 소성! 아래 Step 4로 →
```

### Step 4: 소성 보정 (Return Mapping)
```
경화(연화) 계수 계산:
  H = (H0/3) · |1 - S/S̃|^a · sign(1 - S/S̃)

  현재 모델에서는 Ysat(2.0) < Y0(3.1)이므로 H < 0 → "연화"
  즉, 소성 변형이 일어날수록 재료가 약해짐

소성 보정량:
  dΓ = (τ̄_tr - S) / (G + H)       ← 항복점 초과분을 보정

소성 유동 속도:
  νP = dΓ / Δt                     ← SDV10
```

### Step 5: 상태 변수 갱신
```
Fp_new = exp(Δt · Dp) · Fp_old     ← 소성 변형 구배 (Exponential map)

gBarP_new = gBarP_old + Δt · νP    ← 누적 소성 전단 변형률 (SDV13)
eBarP_new = gBarP / √3             ← 등가 소성 변형률 (SDV14)

S_new = S_old + H · Δt · νP        ← 전단 저항 갱신 (SDV11)
Y_new = √3 · S_new                 ← 항복 응력 갱신 (SDV12)
```

### Step 6: 응력 계산 및 출력
```
Fe_new = F · (Fp_new · Fg_new)⁻¹   ← 최종 탄성 변형
Me_new = 2G·Ee0 + K·tr(Ee)·I       ← Mandel 응력
T = Re · Me · Reᵀ / det(Fe)        ← Cauchy 응력 (Abaqus에 전달)
```

### 전체 인과관계 요약
```
외부 하중 (압력 0.1 MPa) + 리튬 성장 (Fg)
              ↓
       응력 발생 (τ̄)
              ↓
      τ̄ > S ?  ──No──→  탄성, 변화 없음
              │
             Yes
              ↓
       소성 변형 발생 (νP > 0)
              ↓
       소성 변형률 누적 (eBarP ↑)
              ↓
       S 감소 (Y: 3.1 → 2.0 MPa) ← Voce 연화
              ↓
       재료가 더 약해짐
              ↓
       같은 하중에도 더 쉽게 항복
              ↓
       ... 반복 (Ysat = 2.0에서 포화)
```

## 5. Coldspot 메커니즘 상세

### 충방전 사이클 (2160초 주기)
```
cdot
 +103 ┤■■■■■■■■■■■■■■■
      │                ← 충전 (Plating)
    0 ┤───────────────┬───────────────┬──
      │               │               │
 -103 ┤               ■■■■■■■■■■■■■■■│
      │                 ← 방전 (Stripping)
      └───────────────────────────────→ t
      0            2160           4320   (초)
```

### Coldspot에서의 차등 성장
```
                 cdot
x < 9    :  103.643        ← 정상 속도
x = 9~11 :  103.643 / 10  ← 1/10 속도 (Coldspot)
x > 11   :  103.643        ← 정상 속도

결과: 주변은 빠르게 팽창하지만, Coldspot은 느리게 팽창
     → 이 차이가 중앙부를 움푹 들어가게 만듦
```

## 6. 원본 점소성 → 탄성-소성 변경 요약

| 항목 | 원본 (Viscoplastic) | 현재 (Elastic-Plastic) |
|---|---|---|
| 유동 법칙 | νP = ν₀·(τ̄/S - 1)^(1/m) | dΓ = (τ̄ - S) / (G + H) |
| 속도 의존성 | 있음 (ν₀, m 필요) | **없음** |
| 경화 모델 | 단순 선형 | **Voce형 포화 연화** |
| 항복 조건 | 항상 소성 유동 | **명확한 탄성/소성 경계** |
| 성장(Growth) | F = Fe·Fp·Fg | F = Fe·Fp·Fg (동일) |
| 소성 적분 | Exponential map | Exponential map (동일) |
